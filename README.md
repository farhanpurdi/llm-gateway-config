# LLM Gateway Configuration

Configuration repository for the company's LiteLLM gateway.

## Purpose

This repository defines:

- LiteLLM runtime configuration
- Internal logical models
- Provider metadata
- Internal model catalog

## Repository Structure

```text
config/
  Runtime LiteLLM configuration.

models/
  Internal logical model definitions.

providers/
  Metadata for enabled LLM providers.

docs/
  Documentation for developers and platform operators.

scripts/
  Configuration validation utilities.
